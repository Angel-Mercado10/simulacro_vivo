# Bitácora diaria

Un archivo Markdown por día (`YYYY-MM-DD.md`) con todo lo hecho en el proyecto:
decisiones, comandos, salidas reales, métricas, costos, pendientes y siguiente
paso. Existe para que el trabajo no dependa del contexto de una sesión: quien
retome el proyecto lee la bitácora y sabe exactamente dónde quedó.

Reglas:

- Cada sesión de trabajo agrega su registro al archivo del día, sin reescribir
  días anteriores.
- Nada se registra como hecho sin evidencia: comando ejecutado y salida real,
  archivo creado o métrica medida.
- Lo no comprobado se marca `[POR VERIFICAR]` o `[HIPÓTESIS]`, nunca como hecho.
- La bitácora no guarda secretos ni fotos de la casa; solo rutas locales y
  resultados.
- Cada día cierra con el reporte de la sección 15 del super-prompt o un enlace
  a él dentro del mismo archivo.
